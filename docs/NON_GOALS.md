# Non-goals and boundaries

VC4QI specifies and demonstrates conditions for QI reliance. It does not create
institutional authority or prove physical sample truth from digital identifiers.

This migration does not require a full wallet, LIMS/service deployment, general ontology
reasoner, unrestricted rules engine, timestamp-service infrastructure, DPP vocabulary,
or live institutional integration. Issuer-supplied executable code is not a supported
semantic extension. EBSI/EUDI or legal/eIDAS conformance requires separate version-specific
evidence and is not claimed by local fictional fixtures.

The baseline supports explicitly profiled quantities and current reliance. Unsupported
semantics and missing historical evidence remain not established. Recognition, signatures,
query matching and schemas each establish only their specified predicates; none alone
establishes the complete reliance request. See [MODEL_SPEC](MODEL_SPEC.md) and
[implementation status](IMPLEMENTATION_STATUS.md).
