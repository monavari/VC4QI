# Architecture decisions

Architecture Decision Records (ADRs) keep the reasoning behind major choices.
[ADR-010](adr-010-standards-first-reliance.md) is the current foundation.

| ADR | Decision | Status |
| --- | --- | --- |
| [000](adr-000-adr-process.md) | ADR process | Accepted |
| [001](adr-001-polyglot-architecture.md) | TypeScript canonical, Python mirror | Accepted |
| [003](adr-003-bitstring-status-list.md) | Bitstring Status List for status | Accepted, with ADR-010 requirements |
| [006](adr-006-no-dlt.md) | No distributed ledger | Accepted |
| [010](adr-010-standards-first-reliance.md) | Standards-first bindings and reliance evaluation | Accepted; implemented |

ADRs 002, 004, 005, 006 (evidence graph), 007, 008 and 009 described the v0.1–v0.3
models and were superseded by ADR-010. They were removed in v0.4 and remain in the
repository at tag [`v0.3.0`](https://github.com/monavari/VC4QI/tree/v0.3.0/docs/adrs).
